🆘 PROBLEMES COURANTS

❌ "Python n'est pas reconnu" (Version Python uniquement)
   → Python n'est pas installé ou pas dans le PATH
   → Réinstaller Python en cochant "Add to PATH"

❌ L'application ne s'ouvre pas (Version EXE)
   → Vérifier que l'antivirus ne bloque pas
   → Ajouter une exception si nécessaire

❌ "Module flask not found" (Version Python)
   → Lancer : installer_dependances.bat
